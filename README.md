## Çalıştırma 

Yerel bir sunucu (Live Server) ile index.html dosyasını tarayıcıda açın.

VS Code için;
1. Proje klasörünü [Visual Studio Code](https://code.visualstudio.com/) ile açın.
2. "View" menüsünden "Extensions" seçeneğine tıklayarak veya Ctrl+Shift+X kombinasyonunu tuşlayarak Eklentiler panelini açın.
3. Açılan panele "Live Server" yazın ve [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) eklentisini kurun.
   - **Not:** Kurulumdan sonra editörü yeniden başlatmanız gerekebilir.
4. "View" menüsünden "Explorer" seçeneğine tıklayarak veya Ctrl+Shift+E kombinasyonunu tuşlayarak Dosya Ağacı panelini açın.
5. Dosya ağacında `index.html` dosyasına sağ tıklayın ve **"Open with Live Server"** seçeneğine tıklayın.
